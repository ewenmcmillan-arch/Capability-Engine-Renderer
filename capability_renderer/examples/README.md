# Examples

One folder per distance bucket (5k, 10k, half, marathon, ultra),
each intended to hold a matching config JSON + GPX pair once real
session data is available for that distance.

Currently only `5k/sample_run.json` is populated (from
`run_20260731.json`, a genuine 3.44 mi / 32:20 session) — it has no
paired GPX, so it can't be rendered standalone yet. The other
buckets are empty placeholders.
