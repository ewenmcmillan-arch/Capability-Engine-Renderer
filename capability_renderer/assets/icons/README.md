# Icons

Not yet supplied: `cadence.svg`, `elevation.svg`, `recovery.svg`,
`weather.svg`, `route.svg`.

The current locked layout draws its few icon-like marks (the
elevation panel's up/down chevrons, the heart-rate glyph) directly
as PIL line/text primitives in the relevant panels/*.py file rather
than loading an icon asset. Real SVG icons would be consumed by
graphics.py once added here.
